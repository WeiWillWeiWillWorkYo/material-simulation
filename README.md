# Unified Material Simulation Framework for Physical AI

Physical AIのための統一材料シミュレーションフレームワーク

A particle-based research demo by Wei CUI, University of Tsukuba.

The video compares rigid material with fracture, elastic, elastoplastic and plastic materials within a single simulator.

## Watch

https://weiwillweiwillworkyo.github.io/material-simulation/

The page is in Japanese and English. The original demonstration video is available under `assets/four-materials.mp4`.

This repository contains only the presentation video, its poster image and the public showcase page. It does not contain the simulator source code or paper manuscript.
